01 / REALIDAD VIRTUAL
Experiencia inmersiva

Lumini - Realidad Virtual

Lumini es un proyecto académico enfocado en el desarrollo de una experiencia de realidad virtual de una tienda de velas.
La propuesta permite explorar un entorno digital e interactuar elementos diseñados para generar una experiencia inmersiva.

Objetivo

Desarrollar una experiencia virtual que permita al usuario explorar un entorno digital mediante herramienta de realidad virtual (Unity).

Necesidad que aborda

Busca ofrecer una experiencia diferente a los medios tradicionales, incorporando interacción y exploración dentro de un espacio digital.

Herramientas utilizadas

Unity 6 XR Realidad Virtual Diseño 3D

Proceso de desarrolo

Se trabajó en la creación del entorno virtual, incorporación de elementos, configuración de interaciones y pruebas de funcionamiento.

Funcionalidades y aprendizajes

El proyecto permite explorar un entorno virtual. Durante su desarrollo se fortalecieron conocimientos sobre Unity, configuración XR y diseño de experiencias inmersivas.

02 / REALIDAD AUMENTADA
Experiencia interactiva

MilkyCake - Realidad Aumentada

MilkyCake es un proyecto académico que utiliza realidad aumentada para integrar contenido digital con el entorno físico.
Su propuesta busca complementar la presentación de un producto mediante elementos visuales interactivos.

Objetivo

Crear una experiencia de realidad aumentada que permita visualizar contenido digital relacionado con el producto.

Necesidad que aborda

Busca hacer más dinámica la presentación de un producto, utilizando tecnología para complementar la experiencia visual.

Herramientas utilizadas

Unity AR Foundation Realidad Aumentada Blender

Proceso de desarrollo

Se planificó la experiencia, se prepararon los recursos visuales, se configuró el entorno de realidad aumentada y se realizaron pruebas.

Funcionalidades y aprendizajes

Integra contenido virtual con el entorno real. Permitió fortalecer conocimientos sobre AR Foundation, Blender, Unity y desarrollo de experiencias interactivas.

03 / DESARROLLO DE SOFTWARE
Aplicación de escritorio

BeautyLab

BeautyLab es una aplicación de escritorio orientada al maquillaje y la belleza. Integra una interfaz gráfica con inteligencia artificial para generar propuestas relacionadas con estilos de maquillaje.

Objetivo

Desarrollar una herramienta interactiva que facilite la generación de ideas de maquillaje mediante inteligencia artificial.

Necesidad que aborda

Ofrece una alternativa para obtener inspiración al elegir estilos de maquillaje, mediante una aplicación sencilla e interactiva.

Herramientas utilizadas

Python PySide6 Gemini API Visual Studio Code

Proceso de desarrollo

Se diseñó la interfaz gráfica, se organizaron los componentes visuales y se trabajó en la integración con el servicio de inteligencia artificial
para procesar las solicitudes.

Funcionalidades y aprendizajes

Permite ingresar solicitudes y visualizar resultados generados mediante IA. Se reforzaron conocimientos de Python, interfaces gráficas e integración de API.

04 / SISTEMA DE GESTIÓN
Gestión veterinaria

ProVetCare

ProVetCare es una propuesta de aplicación para la gestión de citas veterinarias. Está diseñada para facilitar la organización de la atención de las mascotas, la consulta de información relacionada con sus citas e historial.

Objetivo

Diseñar un sistema que contribuya a organizar las citas veterinarias y mejorar el acceso a la información de las mascotas.

Necesidad que aborda

Busca facilitar la organización de citas y la consulta de información veterinaria mediante una aplicación centralizada.

Herramientas utilizadas

Python SQL Server Visual Studio Code Base de datos

Proceso de desarrollo

Se identificaron las necesidades de los usuarios, se planificaron las funcionalidades, se diseñó la aplicación y se trabajó en la conexión con la base de datos.

Funcionalidades y aprendizajes

Contempla la consulta de citas y del historial de las mascotas, además de opciones administrativas para la clínica. Permitió practicar programación, bases de datos y análisis de necesidades.
